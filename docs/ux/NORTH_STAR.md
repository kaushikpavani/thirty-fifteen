# North star — 30/15

## Spirit

A tool to get better. “You can do it.” Optional sign-in. Guests stay phone-only.
Signed-in riders may sync history to the dedicated 30/15 backend. Never charge money.

## Visual bar

Match **Apple Fitness / Health / Settings** craft:

- One clear primary action per screen.
- Large titles where Apple would use them.
- Grouped inset lists in Settings.
- Monospaced digits for watts, BPM, and countdown.
- Glanceable ride UI: big metric, quiet chrome.
- Portrait only for v1. **No tab bar.**

## Keep

- Louder phase color wash behind the ride (HARD hot, EASY cool, warm-up calm).
- Countdown as secondary hero under watts.
- Pause-only while running.
- Bloom Done (“You did it.” / “Great focus. Strong work.”).
- Music as paint breath, not a second product.
- Abstract bike / road wash ≤15% opacity under the ride clock. Reduce Motion = static phase color.
- Home: sensor chips + large Start + Why 30/15 + Settings.

## Kill (reject as-is)

- Gym-HIIT athlete full-bleed photography.
- ROUND / EXERCISE chrome, Work/Rest/Rounds maze.
- Ring-as-watt-dial as the primary meter.
- Streak Finish, remind-tomorrow, engagement nagging.
- Fake watts or fake BPM when disconnected.
- FTP / hard W / easy W controls on Home.
- Gating Start on sensors or account.
